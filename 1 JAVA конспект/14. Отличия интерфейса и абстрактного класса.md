## 🔷 1. **Наследование и реализация**

| |Интерфейс                         |Абстрактный класс|
|---|---|---|
|Наследование|`implements`|`extends`|
|Множественное наследование|✅ Да (можно реализовать несколько интерфейсов)|❌ Нет (только один родительский класс)|
```java
class MyClass implements A, B {} // OK
class MyClass extends Base1, Base2 {} // Ошибка
```

---

## 🔷 2. **Методы**

| |Интерфейс|Абстрактный класс|
|---|---|---|
|Абстрактные методы|✅ Да|✅ Да|
|Реализация методов (с телом)|✅ Да (с `default` или `static`)|✅ Да|
|Конструкторы|❌ Нет|✅ Да|
```java
interface A {
    void doSomething();            // абстрактный
    default void hello() {         // с реализацией
        System.out.println("Hi");
    }
}

abstract class B {
    abstract void doSomething();
    void hello() {
        System.out.println("Hi");
    }
}
```

---

## 🔷 3. **Поля**

| |Интерфейс|Абстрактный класс|
|---|---|---|
|Переменные|Только `public static final` (константы)|Любые: `private`, `protected`, `non-final` и т.д.|`
```java
interface A {
    int VALUE = 10; // public static final по умолчанию
}

abstract class B {
    int value; // можно обычную переменную
}
```

---

## 🔷 4. **Конструкторы**

- Интерфейс — **не может** иметь конструктор.
    
- Абстрактный класс — **может** иметь, даже если он не используется напрямую.
    

---

## 🔷 5. **Когда использовать**

|Хочешь|Используй|
|---|---|
|Описать **поведение**|Интерфейс|
|Описать **сущность/шаблон**|Абстрактный класс|
|Множественное наследование|Интерфейс|
|Общий код, поля, конструкторы|Абстрактный класс|
