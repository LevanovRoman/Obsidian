Spring Framework — это **мощный фреймворк для разработки корпоративных Java-приложений**, который основан на принципах **инверсии управления (IoC)** и **аспектно-ориентированного программирования (AOP)**.

Он состоит из **модульной архитектуры** — ты можешь использовать только те модули, которые нужны тебе.

### **1. Core Container (Ядро)**

🔹 **Spring Core**

- Основные компоненты: контейнер IoC (инверсии управления), внедрение зависимостей (`@Component`, `@Autowired` и т.п.)
    

🔹 **Spring Beans**

- Механизмы определения и управления жизненным циклом бинов.
    

🔹 **Spring Context**

- Расширяет `BeanFactory`, предоставляет доступ к Spring-контейнеру (например, `ApplicationContext`).
    

🔹 **Spring Expression Language (SpEL)**

- Язык выражений, используется в `@Value`, `@Conditional`, SpEL-логика в аннотациях.
    

---

### **2. Spring AOP**

🔹 Позволяет внедрять **аспекты**: логирование, безопасность, транзакции — **без изменения бизнес-кода**.  
Основан на прокси-объектах (JDK или CGLIB).

---

### **3. Spring Data Access / Integration**

🔹 **JDBC**

- Упрощённая работа с базами данных (`JdbcTemplate`).
    

🔹 **ORM**

- Интеграция с Hibernate, JPA, MyBatis и др.
    

🔹 **Transactions**

- Декларативное управление транзакциями (`@Transactional`).
    

---

### **4. Spring Web**

🔹 **Spring Web MVC**

- Модуль для создания веб-приложений: контроллеры (`@Controller`), маршрутизация (`@RequestMapping`), обработка форм и REST.
    

🔹 **Spring Web WebSocket, WebClient и другие подмодули**

---

### **5. Spring Test**

🔹 Средства для интеграционного и unit-тестирования с поддержкой JUnit, Mockito, MockMvc и т.д.

---

## 📦 Дополнительно (Spring Projects)

Spring Framework — это основа для многих **дополнительных проектов**, таких как:

|Проект|Назначение|
|---|---|
|**Spring Boot**|Автоконфигурация, упрощение настройки|
|**Spring Security**|Безопасность: авторизация, аутентификация|
|**Spring Data**|Работа с базами: JPA, MongoDB, Redis|
|**Spring Cloud**|Микросервисы, конфигурация, сервис-дискавери|
|**Spring Batch**|Пакетная обработка данных|
|**Spring Integration**|Интеграция между системами|
|**Spring WebFlux**|Реактивное программирование (на основе Project Reactor)|
