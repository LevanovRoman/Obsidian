**REST API (Representational State Transfer Application Programming Interface)** — это архитектурный стиль для создания веб-сервисов, который использует стандартные HTTP-методы (GET, POST, PUT, DELETE и др.) для обмена данными между клиентом и сервером. Вот ключевые аспекты:

---

### 🔹 **Основные принципы REST**

1. **Stateless (без состояния)**  
    Каждый запрос содержит всю информацию для его обработки. Сервер не хранит данные о сессиях клиента.
    
2. **Ресурсы (Resources)**  
    Данные представлены в виде ресурсов с уникальными URI (например, `/api/users/123`).
    
3. **HTTP-методы**
    
    |Метод    |Действие              |Пример                             |
    |---          |---                          |---                                      |
    |GET         |Получить ресурс  |`GET /api/users`             |
    |POST       |Создать ресурс     |`POST /api/users`           |
    |PUT         |Обновить ресурс  |`PUT /api/users/123`      |
    |DELETE    |Удалить ресурс     |`DELETE /api/users/123`|
    
4. **Представление данных**  
    Данные передаются в форматах JSON или XML (чаще JSON)

---

### 🔹 **Ключевые характеристики**

1. **Кэширование**  
    Поддержка HTTP-кэширования (`Cache-Control`, `ETag`).
    
2. **Единообразие интерфейса**  
    Стандартные HTTP-статусы:
    
    - `200 OK` — успешный запрос
        
    - `201 Created` — ресурс создан
        
    - `400 Bad Request` — ошибка клиента
        
    - `404 Not Found` — ресурс не существует
        
    - `500 Internal Server Error` — ошибка сервера
        
3. **Многоуровневая система**  
    Возможность использования прокси, балансировщиков нагрузки.
    

---

### 🔹 **Отличие от SOAP**

|Характеристика|REST API|SOAP|
|---|---|---|
|**Формат**|JSON/XML|Только XML|
|**Протокол**|HTTP|HTTP/SMTP|
|**Гибкость**|Высокая|Жесткая структура|
|**Производительность**|Легковесный|Более тяжелый|

---

### 🔹 **Где применяется?**

1. Мобильные приложения
    
2. Веб-приложения (Frontend + Backend)
    
3. Микросервисная архитектура
    
4. Интеграция с внешними сервисами (платежи, соцсети)
